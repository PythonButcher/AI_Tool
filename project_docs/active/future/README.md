# Future Planning Hub

This is the only active-folder location for deferred plans. These records are not current gates and must not be implemented unless the current status file or explicit user direction promotes one into an approved active workspace.

Future proposals are grouped by authoring agent so competing analyses remain easy to compare and provenance is not blurred.

| Origin | Area | File | Purpose |
| --- | --- | --- | --- |
| Antigravity | AI Chat and Decision Intelligence | `ai_chat_di_functional_gap_audit.md` | Source audit of disconnected features and usability gaps. |
| Antigravity | AI Chat and Decision Intelligence | `ai_chat_di_ui_audit_and_repair_plan.md` | Deferred UI-focused audit retained as supporting analysis, not an active execution plan. |
| Codex | Codex future proposals | `codex/README.md` | Navigation for Codex-authored audits, plans, and deferred goals. |

Completed plans and handoffs belong in their owning area's `completed/` folder. Do not create another `future/` directory under an active sub-area.
