# Status Boundary

`project_execution_status.md` is the concise human-readable current truth. `phase_authorization.json` is the canonical machine-readable authorization record. Neither file is a roadmap or work diary.

Status names one current phase, one lifecycle value, one readiness state for each implementation boundary, one current owner, one current milestone, one automatic-continuation state, one required action, and one completion rule. The milestone must exactly match the active gate's current step.

Only Codex may decide roadmap alignment, readiness, gate acceptance, or completion. Antigravity may use the governed status-return skill only to return a completed or blocked handoff to Codex review.
