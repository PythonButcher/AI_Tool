# Gemini Handoff — Fullscreen Saved Decision Review

> COMPLETED REFERENCE ONLY: This handoff is retained for implementation history. It is not active work. Current truth is `project_docs/active/status/decision_intelligence_execution_status.md`.

Goal: Let a user open one already-saved DecisionAsset in an app-scoped full-viewport review overlay. The overlay is a read-only historical review, not browser fullscreen, F11, a new tab, an AI Chat pop-out, or a revived legacy Decisions destination.

Read `project_docs/INDEX.md`, `project_docs/active/README.md`, `project_docs/active/status/decision_intelligence_execution_status.md`, `project_docs/active/decision_intelligence/completed/phase_2_fullscreen_decision_asset_review_architecture.md`, `project_docs/active/contracts/decision_objects.md`, and this handoff before editing. Read `frontend/frontend/src/features/business/decision/DecisionAssetLibrary.jsx` and `frontend/frontend/src/features/business/decision/decisionApi.js` only as source context: they already list and retrieve the complete saved asset. `frontend/frontend/src/components/layout/CanvasContainer.jsx` already mounts the AI Chat window; do not change it for this slice.

Modify only `frontend/frontend/src/features/ai/AIShell.jsx` for the implementation. Add a MUI `Dialog` with `fullScreen` that overlays the app viewport while AI Chat remains mounted underneath. Do not use `requestFullscreen`, browser APIs, Canvas `WindowFrame` maximize/pop-out behavior, or a new route. Add the visible `Open full review` control only when the active artifact is a saved asset with `asset_id`.

The overlay has one fixed review header and one scrollable review body. The header identifies the view as a saved Decision Review and provides a clearly labeled close control. The body reuses the existing `renderArtifact(fullscreenAsset, true, ...)` Decision Review path; it is not a shortened summary, a new renderer, or a second copy of the existing section layout. Escape and the close control dismiss the overlay and return the user to the unchanged regular results pane. Do not create a new review component or duplicate the decision-output renderer.

`AIShell.jsx` owns the state. Keep the existing `activeArtifact` and `handleReopenAsset` flow unchanged: `DecisionAssetLibrary` retrieves the full asset through `getDecisionAssetById`, then `handleReopenAsset` places it in the existing results pane. Add one local `fullscreenAsset` state value. `null` means closed; the exact complete saved asset object means open. On open, assign the current saved `activeArtifact` to that state. On close or Escape, set it back to `null`. Do not fetch, normalize, merge, mutate, save, or refresh the asset when opening the overlay.

Treat the asset as immutable. Preserve `asset_id`, `schema_version`, `title`, `created_at`, `decision_output`, optional `graph_state`, and `snapshot_notice`. Pass the same asset object to the existing renderer so its `decision_output` retains `dataset_trust`, `source_refs`, `export_sections`, and `truth_boundary: observational_analysis_only`. Existing saved-asset conditions must continue to keep corrections and save controls unavailable. Do not add edits, deletes, sharing, comparison, live refresh, new persistence, route changes, or legacy Decisions navigation.

Run `npm --prefix frontend\frontend run build` and `git diff --check`. Do not run browser acceptance. Update `project_docs/active/status/decision_intelligence_execution_status.md` only with the build result and the exact implementation fact after those checks pass.

User manual acceptance checks: select an existing saved snapshot from the AI Chat library, then choose `Open full review`. Confirm an app-scoped overlay covers the app viewport without opening a browser fullscreen mode, tab, route, or pop-out. Confirm its fixed header has a close control and its scrollable body shows the selected title, saved timestamp, snapshot notice, Dataset Trust, export sections, and observational-only boundary. Close it with both the control and Escape; each time, confirm the same saved asset remains selected in the regular results pane. Confirm an unsaved AI Chat decision output does not show the control.
