# Archive Documentation

Everything under `project_docs/archive/` is historical reference material.

Do not use archive files as current implementation plans, current handoffs, current contracts, or current status. Some archived documents may still contain old language such as "active", "next", "source of truth", or "handoff" because that was true when they were written.

For current work, start with `project_docs/INDEX.md` and `project_docs/active/README.md`.
